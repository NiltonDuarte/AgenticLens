**Severity 2; introduced in the new publication path.** Location: `backend/internal/adapters/workspace_publication.go:74–110`, with caller `backend/cmd/agentic-lens/main.go:1985` and read-reference lifetime in `backend/internal/adapters/repository.go:177`.

The CLI first loads an explicitly selected ledger, closes its physical-directory reference, then calls `PublishWorkspaceArtifacts`. That function carries only `WorkspacePath` and ticket ID into a new lease. If selected directory A moves and a distinct same-ticket copy B replaces its pathname between these calls, the new lease binds B. The ticket comparison passes, and export/summary publication modifies B successfully. This violates the approved concurrent-movement requirement to avoid writes to an unrelated replacement and the design's requirement that replaced destinations produce recoverable retry. Same-ticket copies are explicitly supported and remain distinct; matching ticket text cannot establish that this is the selected physical copy.

The stable-directory control passes; the replacement case fails the required rejection assertion. Full output: `build/al84-astra-review/data-admission-20261117/result.log`.
