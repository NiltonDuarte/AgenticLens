# Recommend safe backfill defaults

Determine when ordinary backfill can refresh exact recorded sessions without losing portable history. The [roadmap ticket](../../../alspaces/plan/done/AL-65%20recommend%20safe%20source%20backed%20backfill%20defaults.md) asks for an operator recommendation, evidence and transition options.

The roadmap splits the recommendation into [AL-94](../../../alspaces/plan/to-do/AL-94%20make%20explicit%20backfill%20repeatable%20and%20report%20refresh%20coverage.md) for safe explicit refresh and [AL-95](../../../alspaces/plan/to-do/AL-95%20preview%20source%20backed%20defaults%20and%20decide%20on%20rollout.md) for the dependent preview and rollout decision. FIX-19 owns ambiguous Codex snapshots, FIX-20 owns cancellation, and REV-7 owns the broader source-read contract.
