# CONTEXT HANDOFF & EXECUTION PROMPT: TICKET AL2-10

## 1. Background & Context from Exploration Session

During the architecture and domain exploration of ticket AL2-6 ("Estimate API-equivalent costs alongside measured spend"), the following technical decisions and domain rules were established:

### Cost & Token Semantics in AgenticLens
1. **Measured vs. Estimated Cost**:
   - `measured_cost_usd` is authoritative recorded billing evidence (`observed`, `partial`, or `unavailable`).
   - AL2-6 introduces a 3-tier rate card formula for unavailable facts:
     `(uncached_input * rate_in + cache_read * rate_cache + output * rate_out) / 1,000,000`
   - At the atomic fact grain (`InvocationFact`), equivalent cost is a selection (`COALESCE(measured, estimate)`). An invocation never has both.
   - At the OLAP rollup grain (`ModelMetric`, `Totals`, `FleetSummary`), it is an additive aggregation (`SUM`) with explicit coverage and provenance (`measured`, `estimated`, `hybrid`, `unavailable`).

2. **Token Categories in AgenticLens Domain (`InvocationTokens`)**:
   - `Input`: Represents strictly *uncached* input prompt tokens.
     - In Codex (`rollout.go`): `uncachedInput := usage.Input - usage.CacheRead`.
     - In Claude Code & OpenCode: `input_tokens` is already uncached.
   - `CacheRead`: Tokens served from the provider's prompt cache (KV-cache hit), billed at a discount (`rate_cache`).
   - `Output`: Every token generated by the model's forward pass (tool call JSONs, internal reasoning/thinking tokens in `Tokens.Reasoning`, intermediate subagent messages, and final user Markdown).

3. **Cache Write / Cache Creation Discrepancy & Provider Asymmetry**:
   - **OpenAI (Codex / GPT-4o / o1) & DeepSeek**: Prompt caching is automatic. Cache writes have $0 surcharge and are billed at standard base input rate. The 3-tier formula is 100% exact.
   - **Anthropic Claude**: Explicit prompt caching incurs a 25% surcharge (1.25x base input rate) for `cache_creation_input_tokens`, while cache reads receive a 90% discount.
   - **Current Domain Limitation**: `domain.InvocationTokens` currently only stores `Input`, `Output`, `CacheRead`, `Reasoning`, and `PeakContext`. Raw transcript fields (`usage.CacheWrite` in Codex, `rawUsage.CacheCreation` in Claude Code, and `cache.write` in OpenCode schema v2) were previously dropped at the adapter boundary.
   - **Schema v6 Constraint**: Adapters enforce strict decoding with `DisallowUnknownFields()`. Adding a `cache_write` field to `agentic_metrics.json` without a coordinated schema migration (Schema v7) would break backward compatibility with older binaries.

4. **Roadmap Decision**:
   - AL2-6 will remain focused on its approved 3-tier contract (`input`, `cache_read`, `output`).
   - A dedicated ticket **`AL2-10`** is required to formally add `CacheWrite` tokens across adapters, domain models, schema definitions, and 4-tier rate card pricing.
   - AL2-10 must be linked to and blocked by AL2-6.
