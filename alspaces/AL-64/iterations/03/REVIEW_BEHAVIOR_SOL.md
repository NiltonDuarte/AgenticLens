### BEH-SOL-02: legacy numeric nulls become recorded zero

- Severity: **3/10**. Classification: carried-forward draft validation debt exposed at the newly introduced normalization boundary; not an introduced null-acceptance regression. Reported for consolidation against the approved integer/non-null input contract, independently of BEH-SOL-01.
- Location: `backend/internal/domain/migration/duration_decode.go:14-18,45-55`.
- Trigger: compatible-looking draft evidence has `completed_seconds:null` with provisional equal to total, or `provisional_seconds:null` with completed equal to total.
- Expected: reject a null numeric component rather than treating it as an integer zero before checking consistency and projecting canonical facts.
- Actual: JSON decoding into `int64` silently converts null to zero. Component equality then passes, and canonical conversion discards the original invalid representation. Runtime validation, invocation DTO decoding and current-schema migration all accept it.
- Evidence: isolated `TestReviewDraftNullRuntime` uses a valid 11-second ledger and exercises both forms through `ValidateRuntimeFactLedger`, `json.Unmarshal` into `AgenticFactLedgerDTO`, and `migration.NewEngine(nil).Migrate`. All six calls return nil errors. A direct helper probe independently confirms null completed maps to an all-provisional amount and null provisional maps to zero.
- Baseline check: `git show c68fbc90:backend/internal/domain/duration.go` and the prior typed draft model show that legacy null acceptance existed before this iteration. The new observable consequence is irreversible projection into canonical numerics. Do not attribute the underlying acceptance as a newly introduced regression.

## Consequential hypotheses investigated

- **Completion adds to provisional history instead of replacing it:** refuted for the inspected main paths. CLI `mergeSessions`, backfill `replaceRecoveredOwners`, and retained-history filtering replace exact successfully refreshed owners; unchanged/unavailable owners remain outside the replacement set. Source-family matrix tests exercise open growth, fixed-cutoff repeats, completion replacement and repeat without accumulation across Codex/OpenCode v1/v2.
- **A missing source drops historical numeric duration or changes harness ownership:** refuted in the inspected paths and reused tests. Retained DTOs normalize before domain use, generation retains unavailable owners, registered snapshot decoding normalizes draft input without rewriting stored registry bytes, and merge/source validation remains in force. No private receipt requirement was added. The documented pre-existing disabled-delegation registry cache issue was not reclassified as introduced by this change.
- **Cutoff or rounding changes total/provisional inclusion:** refuted by source trace and reviewed tests. Pure `MeasuredDuration` rounds the invocation total once and assigns its difference from rounded completed milliseconds to the provisional scalar. Both source families preserve their existing native activity boundaries; Codex malformed lifecycle diagnostics reach strict replacement guards, and invalid OpenCode intervals return errors. Source-open stopped processes remain the explicitly accepted estimation limitation, not a review blocker.
- **Aggregate totals add provisional twice, lose it, or average it over another population:** refuted for workflow/fleet/comparison/progression paths inspected. Go and TypeScript accumulate total and provisional independently without adding the latter into total. DTOs propagate the scalar with zero omission. Comparison average total and provisional use the same `filteredRows.length` denominator and `Math.round`; the former fleet subtotal description was removed.
- **Zero/absence claims source completion or requires retired frontend metadata:** refuted for inspected summary/table/KPI/scatter consumers. Labels say recorded duration, show a positive provisional amount, and make no completed-coverage claim for zero/absence. Frontend decoders validate the scalar and do not perform legacy conversion. No duration-reasoning dependency or new configuration precedence was observed.
