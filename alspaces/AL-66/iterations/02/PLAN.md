## Representation and authority decisions

Domain and DTO category slices use nil for unrecorded, allocated empty for recorded-empty and nonempty for recorded facts. Use explicit presence-aware JSON encoding at the boundary; no serializer may indiscriminately replace nil with empty, or use omitempty that removes allocated empty arrays. Go has no need for a new persisted enum or another schema version. Source coverage is transient typed state; do not persist copies of source events or private receipts.

Recorded facts remain valid without fresh source access. An absent owner category stays absent under ordinary read, save, non-source backfill or unavailable/partial source recovery. A successful complete supported source snapshot can replace that exact owner's category with empty or nonempty. The same rule applies independently to skills, delegations and anomalies. Genuine unsupported category evidence stays absent even when other categories for that owner are complete. Root anomaly analysis becomes recorded-empty only after its required complete source coverage, not merely an empty derived result. Persist existing known root/group summaries until an authoritative complete source refresh can replace them.

In partial coverage, show known rows and label totals as recorded/partial where needed; do not report an unqualified complete zero, healthy status or all-ticket success rate. Compute denominators using complete analyzed populations only, or omit a rate when that population cannot be established from recorded facts. Preserve independent tool execution metrics even when no analysis is recorded. UI labels use not recorded rather than guessing disabled. Current generate alone can explain its disabled config using transient options. No new JSON policy, reason or per-owner availability fields are authorized.
