# AL-63 source capability audit

Operators need to know which harness can supply a missing trace and which saved facts survive a source failure. The deliverable is a versioned matrix for OpenCode v1, OpenCode v2 and Codex, grounded in the eight checks in the [original roadmap ticket](../../../alspaces/plan/done/AL-63%20verify%20source%20capabilities%20across%20harnesses.md).

The OpenSpec capability `source-capability-evidence` describes what the report must demonstrate. This change delivers evidence and findings. Product fixes and backfill policy are separate decisions.
