# feat(capture): automatically publish lifecycle session metrics (AL-68)

Install additive Codex/OpenCode lifecycle integrations that durably register observed sessions, ask the agent for explicit ticket/title/type, and schedule bounded native publication. Independent roots and source-proven children contribute to the same ticket without agent-run generate. Manual generation remains a recovery path.

One user-level wrapper resolves the authoritative repository YAML version and executing platform. Native versions coexist in a shared user cache; machine-local YAML can override paths. Missing binaries require explicit installation, and ordinary commands and installed hooks remain offline. Native workers keep their selected executable for an accepted pass and validate version/installation handoff.

Publication writes the schema-v5 ledger and rendered summary. Detailed attempts, accepted snapshots and publication outcomes remain in a user-level database for diagnostics; capture_report.json is retired, with authorized legacy journal recovery preserved. Available accepted facts survive source failures and limitations remain visible. Snapshot completion describes observability independently of ticket completion.

An explicitly installed, bounded pre-commit check warns about proven missing bindings, missing metrics, capture failures and owned integration drift. It preserves foreign hooks, resolves the committing worktree, remains advisory and supports local disablement. It does not infer which session authored a commit. Setup verification separates installed components from a real, normally trusted callback/binding/source exchange.

New and explicitly updated configuration records ~/.agenticlens/state; operational reads require telemetry.capture.state_dir. A configured project name groups one registry across worktrees, with isolated capture, bindings and worker state. Same-ticket worktrees retain unchanged committed history only with verified repository and source ownership. Explicit legacy relocation preserves pending state and fences old writers; retained diagnostics survive worktree removal. Observed runtime support and current limitations are recorded in [SUMMARY.md](https://github.com/NiltonDuarte/AgenticLens/blob/feat/AL-68-automatic-session-capture-hooks/alspaces/AL-68/SUMMARY.md). Raw transcripts and detailed working reviews remain outside Git; compact REVIEW_SUMMARY.json files preserve findings and every reporting persona/model/effort.
