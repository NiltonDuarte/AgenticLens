# Native checkpoint and publication evidence

The isolated long-turn scenario makes a real code commit, requests manual generation while the native interval is still open, and waits for automatic settlement after the normal response. A deterministic loopback provider records whether the matching native tool result contains the emitted warning. It supplies the final reply. This demonstrates feedback transport and native publication, while the effect of the wording on an autonomous agent remains unmeasured.
