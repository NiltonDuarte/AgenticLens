# GEN-22: Human-readable workspace artifacts

Workspace documents have grown into repetitive execution histories. This ticket
refines the instructions that produce them so a human can quickly understand the
agreed scope, delivered result, evidence and remaining work.

Acceptance:

- One canonical writing standard defines each artifact's purpose, practical prose
  length targets and where evidence belongs.
- Active contributor guidance, personas, relevant skills and the specification
  template agree with that standard.
- Summaries describe current outcomes; routine turns and repeated policy text do
  not accumulate. Required review attribution, verification and unresolved limits
  remain visible.
- GEN-22's own artifacts demonstrate the standard.

The user's opening request authorizes this documentation maintenance. Application
code, generated metric formatting and rewriting historical ticket artifacts are
outside scope. No development approval gate is needed for these documentation edits.
