# REV-3 Contract: Prevent recurring repository mistakes

## Scope

Review all existing REV and FIX ticket workspaces: REV-1, REV-2, and FIX-1 through FIX-15. Turn documented defects and review findings into practical documentation at the points where contributors plan, implement, verify, and deliver changes.

This is documentation-only maintenance authorized by the user request. No application, test, schema, runtime script, configuration, or skill behavior changes. No development delegation or implementation approval gate is required. Classification: docs.

## Acceptance

- Record a ticket-by-ticket evidence inventory and distinguish historical defects, completed corrections, and unresolved recommendations.
- Prefer concise canonical rules and links over copying the entire ticket history into agent instructions.
- Cover fact fidelity, source/tree preservation, configuration propagation, test isolation, optional enrichment, build prerequisites, distribution, and evidence-based handoff.
- Create SUMMARY.md, PULL_REQUEST.md, this contract, iteration plan/review, and final telemetry when available.
- Verify changed documentation links, whitespace, documented Make targets, and the required post-integration make gate. Explicitly report verification and telemetry limitations.
