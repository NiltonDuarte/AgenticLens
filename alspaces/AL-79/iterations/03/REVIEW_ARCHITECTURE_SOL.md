## Findings

1. **ARCH-SOL-01, severity 6/10 — retained Windows consumers still execute the native manager as a PowerShell script.** `backend/internal/adapters/capture/plugin.ts:88-92` chooses `powershell.exe -File <wrapper>` on Windows. The changed installer now validates/substitutes a native manager (`install.go:272-284,418-427`), and `config/entrypoint.go:82` supplies `agentic-lens.exe`. Thus every Windows OpenCode receive/request/bind/verify call selects a script interpreter instead of launching the installed PE executable. Capture fails before the manager can select an engine. The Windows branch of `hooks.go:232` likewise renders project Codex binding feedback with `-File <native-manager>`. These were valid shell-wrapper consumers at the base and become incorrect through the changed producer; retaining Windows runtime and OpenCode integration is explicit in the plan. A Node VM probe transpiled the original `call()` function with Windows context and recorded the actual interpreter/argv, including `-File C:\Users\Fixture\.agenticlens\agentic-lens.exe`. This proves argument construction, not Windows execution. Invoke the native manager directly and preserve bounded process-tree cleanup; update the binding command consistently.

2. **ARCH-SOL-02, severity 4/10 — self-update loses the installed destination.** `backend/internal/adapters/manager/install.go:43-50` defaults to `config.UserManagerPath()` instead of the executing owned installation. Install an owned manager at a supported custom destination, then run its documented `self-update --version EXACT` without repeating `--dest`: it successfully installs another manager under the default home path while the invoked manager and its hooks retain the old build. Real v9.7.1/v9.7.2 manager builds reproduced this offline in `/tmp/al79-arch-selfupdate-umwg94a0`: both operations exited 0; custom identity remained v9.7.1, default identity became v9.7.2. Explicit `--dest` is a workaround. Preserve the running installed destination for self-update while retaining an explicit destination for bootstrap installation.
