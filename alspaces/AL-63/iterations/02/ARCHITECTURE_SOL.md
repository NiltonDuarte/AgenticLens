**AS-1, severity 6/10, existing native child-identity loss.** OpenCode 1.19.5 task records identify their child in `state.metadata.sessionId` and parent in `state.metadata.parentSessionId`. The v1 decoder omits metadata (`backend/internal/adapters/opencode/schema_v1_session_extraction.go:48`), and relationship projection accepts only JSON object task output (`skills_tasks.go:58`, `skills_tasks.go:151`). Seven sampled native completed tasks had non-JSON output, matching metadata parent IDs, and matching native child `session.parent_id`. Thus the relationship is provable but both persisted delegation and source event omit its child ID. The UI consequently displays “Session identity unavailable” and cannot offer the task's child-navigation button (`web/src/components/SkillsSubagentsPanel.tsx:91`, `TraceInvocationBadge.tsx:20`). A child can still appear independently in the thread list; this finding concerns navigation from its delegation.
