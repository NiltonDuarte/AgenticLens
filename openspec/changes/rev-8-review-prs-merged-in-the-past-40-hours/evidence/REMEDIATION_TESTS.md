# REV-8 remediation verification

The regression tests use disposable directories, SQLite databases, and local HTTP connections.

- Generation selects the directory through the same adapter used by the CLI. Tests replace that directory before write admission in implicit, explicit and first-publication flows. Admission rejects the replacements, preserves both copies and allows a fresh selection. A mutation that bypassed physical identity checking failed these assertions.
- The maintenance test holds a real lease on the first target, waits for the batch's writer descriptor, and replaces a later target. Both commands reject same-ticket and different-ticket replacements, preserve both directories, and still update independent targets. All four variants failed against the original implementation.
- The overflow test pauses delivery after a real SQLite diagnostic, fills the subscriber queue, and restores the same database state. The responsive subscriber receives recovery. The stalled stream closes and its reconnected request returns the unchanged tree. The original implementation timed out waiting for stream closure.
- The real-socket probe for the next correction saturated a TCP connection while the client remained open. Closing the overfull subscriber channel alone left the HTTP handler blocked. The corrected production handler returned at the original 15-second server response-write budget. The test suite also exercises the same handoff with a shortened socket deadline.
- Existing Go race checks covered post-admission rename and recovery, native worker publication and project routing, copied-ledger refresh without private registration, legacy and interrupted migration, independent owner retention, and partial discovery. Existing frontend live checks passed all 93 tests and cover reconnect scheduling and cleared diagnostics.
- The Linux manager and engine downloaded from the selected release matched their SHA-256 records. The manager installed the engine in an isolated cache and reported the exact release identity through offline dispatch. It successfully listed a synthetic ledger in that checkout. A control retaining the shared development selector failed when the checkout had no development binary.

The transport probe used a real socket. The frontend tests use simulated EventSource and browser state. Native macOS execution and an end-to-end browser session were outside this run.

The first integrated candidate timed out in an unchanged comparison-view test at the default frontend worker count. The complete frontend lane passed with two workers. The build of the production correction used that worker bound without changing test timeouts. After the production correction, repeated tests exposed a SQLite WAL cleanup race in the new fixture. Waiting for the reader pool to close all driver connections fixed teardown. All four SSE tests passed 15 consecutive race runs and the overflow test passed 30 consecutive race runs with that fixture. The fixture change leaves the behavioral assertions and application code intact.
