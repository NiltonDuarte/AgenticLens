## ADDED Requirements

### Requirement: Evidence for a source-backed default

The recommendation SHALL compare ordinary, forced, source and Git recomputation on complete and partial ledgers and describe compatibility, cost, repeat writes and preservation by source.

#### Scenario: An operator repeats backfill

- **WHEN** exact source records are available, unavailable or only partly readable
- **THEN** the report distinguishes refreshed, unchanged and retained facts and identifies the safeguards and transition required before any default change.
